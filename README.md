# Akkor Hotel Project

This project is a hotel booking application built using **Java 21** and **Spring Boot**.  
It follows the **DDD (Domain-Driven Design)**, **BDD (Behavior-Driven Development)**, and **TDD (Test-Driven Development)** approach.

## 📌 Technologies Used:
- **Java 21** & **Spring Boot**
- **Spring Data JPA** with **PostgreSQL**
- **H2 Database** (for testing)
- **Spring Security** (JWT authentication)
- **Swagger/OpenAPI** (API Documentation)
- **JUnit 5, Mockito, Testcontainers** (Unit & Integration Testing)
- **Git & GitHub Actions** (CI/CD)

## 🚀 How to Install

### 1️⃣ Prerequisites:
- **Java 21** installed (`java -version`)
- **Maven** installed (`mvn -version`)
- **Git** installed (`git --version`)
